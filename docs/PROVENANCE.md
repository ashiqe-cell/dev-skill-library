# Ownership and provenance

Every contribution must be identified as one of:

- **Company-authored:** created and maintained by the named project owner.
- **Adapted:** based on another work and accompanied by compatible licensing, attribution, and a record of changes.
- **Third-party:** upstream work included with permission or a compatible license, preserved attribution, and a pinned source revision.

Do not copy a skill into this repository merely because it is installed locally. Local inventories contain names only and are not evidence of ownership or redistribution rights. Do not include secrets, customer information, generated audit reports, or machine-specific paths.

Each package manifest records its source repository, immutable revision, license, maintainer, and version. Review upstream license terms before importing; retain copyright notices and license files. When provenance is unclear, keep a link in the catalog or issue tracker instead of vendoring the content.
